# 🌦️ Weather-Forecast-Dashboard (Power BI)

![Uploading Dashboard Preview.png…]()

## 📌 Overview
This project is a Weather Analytics Dashboard built using Microsoft Power BI, designed to provide an interactive and visually appealing overview of weather conditions and air quality metrics.
The dashboard presents real-time–style insights for cities in Indonesia, with comparative city views and short-term forecasts.
It focuses on data visualization, user-friendly UI, and decision-support insights. This dashboard uses resources from https://www.weatherapi.com 

## 🎯 Objectives
1. Visualize current weather conditions in a single glance
2. Analyze short-term weather trends
3. Monitor air quality indicators
4. Provide rain probability insights for planning and risk awareness
5. Demonstrate clean dashboard design and analytical storytelling

## 📊 Key Features
### 🌡️ Current Weather Summary
a. Location: Jakarta, Bandung, Yogyakarta, Bali, Malang, Surabaya
b. Current temperature (°C)
c. Weather condition (e.g., light rain)
d. Last updated timestamp
e. Quick comparison with other cities (Surabaya, Yogyakarta)

### 📈 7-Day Temperature Forecast
a. Line chart showing average temperature trends
b. Clear daily comparisons
c. Helps identify warming/cooling patterns

### 🌅 Sunrise & Sunset Information
a. Daily sunrise time
b. Daily sunset time
c. Useful for outdoor activity planning

### 🌧️ Chance of Rain Analysis
a. Bar chart showing daily rain probability (%)
b. Enables risk-aware decision making
c. Visual scale from low to high probability

### 🌬️ Environmental & Atmospheric Metrics
a. Humidity (%)
b. Wind Speed (kph)
c. Visibility
d. Atmospheric Pressure
e. UV Index
f. Precipitation level

### 🏭 Air Quality Index (AQI)
a. Overall AQI classification (Moderate)
b. Pollutant breakdown:
  1. O₃ (Ozone)
  2. PM10
  3. PM2.5
  4. SO₂
  5. NO₂
  6. CO
c. Gauge visualization for quick interpretation

### 🛠️ Tools & Technologies
a. Microsoft Power BI
b. Data modeling & DAX measures
c. Custom visual layout & color theming
d. Interactive filters and cards
